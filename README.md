# local_ai_agent
基于 Python 的本地多模态 AI 智能助手
项目简介：这是一卷本地化部署、零网络依赖的多模态向量检索工具，专注于学术论文的pdf与图像的智能管理，核心实现PDF语义分类+论文向量检索+以文搜图三大核心能力，全程数据私有化，无隐私泄露风险，适配科研/学习场景下的文献与图像高效管理需求。
核心功能亮点：
论文智能处理：PDF自动提取核心内容、生成语义向量、按主题相似度分类归档
精准语义检索：支持自然语言提问，毫秒级检索最相关的学术论文，按相似度排序展示
跨模态图像检索：输入文本描述，精准匹配本地图像库中的相似图片（以文搜图）
本地化存储：基于ChromaDB向量数据库持久化存储，所有数据本地留存，安全可控
高兼容性适配：完美支持Windows中文命令行、自动处理向量维度对齐、文件去重覆盖
健壮异常处理：全流程错误捕获+堆栈打印，支持批量文件处理，单文件失败不阻塞整体任务
环境配置：
Python 3.10
系统支持：Windows 10/11
硬件要求：支持 CPU 运行
依赖说明：
chromadb：本地向量数据库，实现向量增删查
sentence-transformers：多模态编码模型CLIP，生成文本/图像向量
PyPDF2：PDF文件解析，提取核心文本内容
pillow：图像加载与格式转换
click：命令行工具开发，实现CLI指令集
numpy：向量计算、相似度分析
详细使用说明：
所有命令均在项目根目录执行，命令支持相对路径/绝对路径，支持单个文件/文件夹批量处理，中文路径、中文文件名、中文检索词全兼容，无乱码问题.
命令行工具入口
项目所有功能通过命令行指令调入，主入口为根目录的主程序文件main.py，基础调用格式为：python main.py <子命令>[参数][选项]
添加并智能分类核心：python main.py add-paper <文件路径> [--topics 主题1，主题2，主题3] 执行效果：自动创建对应的分类目录，计算每篇论文与各主题的相似度并打印，自动将论文迁移至相似度最高的主题目录，生成论文向量并入库，自动去重，输出每篇论文 的处理状态、相似度值、存储路径。
语义搜索论文：python main.py search-paper <检索关键词>.执行效果：自动清洗检索词，生成检索向量，检索向量库中相似度≥0.4 的论文，按相似度降序排序，展示结果包含：论文文件名、存储路径、主题分类、语义相似度，无匹配结果时友好提示，无冗余警告信息
图片向量入库:python main.py index-images <图片/文件夹路径>.执行效果：自动遍历路径下所有合法图片，生成图像特征向量，向量入库并生成唯一 ID，记录图片路径与文件名，输出批量处理统计：成功数量、失败数量，单张图片失败不影响整体任务。
以文搜图：python main.py search-image <文本描述关键词>.执行效果：生成文本描述的向量，与图片库中向量进行相似度匹配，按相似度降序排序，返回最多5张最相似图片，示结果包含：图片文件名、存储路径、相似度值，自动去重，避免重复展示同一张图片
关键组件选型详情
向量数据库：ChromaDB
选型理由：轻量级本地向量数据库，无需额外部署服务，支持持久化存储，API简洁易用，完美适配Python生态
核心特性：支持向量增删查、元数据过滤、相似度检索，内置L2/余弦相似度计算，适配本项目轻量化需求
优化处理：全局禁用遥测上报、统一向量维度校验、自动处理数据格式转换，彻底消除运行警告
多模态编码模型：CLIP(clip-ViT-B-32)
选型理由：由OpenAI开源的跨模态模型，同时支持文本→向量、图像→向量，输出向量维度统一（512维，项目适配为384维），可直接计算跨模态相似度
核心优势：轻量化、CPU可运行、语义表征能力强，兼顾文本与图像的编码效果，满足「论文检索 + 以文搜图」双需求
优化处理：模型初始化配置use_fast=True消除警告，向量归一化提升匹配精度，强制对齐384维适配数据库
文本编码：自定义哈希+归一化方案
选型理由：无第三方模型依赖，生成向量稳定、唯一，保证相同文本→相同向量，适配论文主题分类与文本检索场景
核心特性：固定384维输出、支持单文本/文本列表批量编码、向量归一化保证相似度计算有效性
PDF 解析：PyPDF2
选型理由：轻量级PDF解析库，无需额外依赖，支持PDF文本提取，适配学术论文的格式特点
优化处理：仅提取PDF标题+摘要+前3页核心内容，抛弃全文冗余信息，提升向量表征精准度与处理速度
图像处理：Pillow(PIL)
选型理由：Python图像处理标准库，支持多格式图片加载、格式转换、RGB统一处理，兼容性极强
核心作用：解决图像格式兼容问题，保证图像编码的一致性
命令行框架：Click
选型理由：Python主流CLI开发框架，支持命令分组、参数解析、选项配置，语法简洁，易于扩展
核心优势：自动生成命令帮助文档、支持中文参数、适配多平台命令行交互
